# تجربة عقارتك في المتصفح (GitHub Codespaces)

كل شيء يعمل وحده: قاعدة البيانات، والخادم، والموقع، والبيانات التجريبية.

1. أول مرة يستغرق التجهيز **حوالي 5–10 دقائق**. انتظر حتى تظهر في الطرفية (Terminal) رسالة:
   `✔ AqarTech is starting`
2. افتح تبويب **PORTS** في الأسفل، ثم اضغط على أيقونة الكرة 🌐 بجانب المنفذ **8081**.
3. ادخل بالحساب التجريبي:
   - البريد: `demo@aqartech.test`
   - كلمة المرور: `Demo@12345`

## إذا ظهر «تعذّر الاتصال بالخادم»
افتح تبويب **PORTS**، واضغط بالزر الأيمن على **3000**، ثم اختر **Port Visibility → Public**، ثم حدّث صفحة الموقع.

## سجلات التشغيل
- الخادم: `tail -f /tmp/aqartech-api.log`
- الموقع: `tail -f /tmp/aqartech-web.log`

## بعد تحديث الكود من GitHub
اكتب في الطرفية:
```
git pull
```
ثم من قائمة Codespaces اختر **Rebuild Container**، أو أعد تشغيل الـ Codespace.

> لإعادة البيانات التجريبية من الصفر: `cd backend && npm run demo:reset`
